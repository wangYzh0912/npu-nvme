# 图内 Top-K：2026-09-17 重新实验

旧队列已停止，完整保存路径的证据单独保留。本轮不包含 NVMe、socket、JSON 协调、payload SHA、介质回读、影子 loss 或 D2H。

主模型 Qwen3-8B，辅模型 Qwen3-4B；TP4、seq128、micro-batch1、FP32 权重/BF16 计算。每配置默认一次，证据不清最多两次；正式区间连续 20 个优化器 step。三档选择比例与扫描比例是独立变量。

## 数据与依赖

G1 非空读取真实权重；G2 真实 W/R 扫描归约；G3 差分；G4 64K 全局逻辑块平方和；G5 独立 TP 通信组聚合；G6 排序 Top-K 和设备输出。q<1 按每个参数循环相位均匀选块，保留各层及参数类型。TP 列切分的部分块先在设备归约，再聚合，不能以局部 Top-K 代替。

参考由确定初始权重建立为 `W_initial * .99 + (parameter_index % 17 + 1) * 1e-5`，固定且非退化。该轮测成本，不评价保存状态误差。初始 FULL 仅在计时外用于恢复模型、Adam、步数和 RNG。

在单个训练图中计算前一更新的 A，再计算下一步 F/B/U。串行变体增加 A→F，目标并行变体仅增加 A→U。图入口的 W 来自上次完成的 U。第一正式训练步跳过辅助分支，之后 19 步处理前一更新；最后独立排空第 20 次更新的 A。因此恰好检测 20 个正式更新后的 W，末尾无法隐藏的辅助成本计入总时间。训练图的副作用规则可能自动加强依赖；“parallel”参数只表示所请求的依赖布局，只有编译图及设备轨迹确认后才报告实际并发。

所有选中索引、分数及检测版本保存在设备。参数写入必须依赖辅助结果，输出缓冲每轮仅在前一轮结束后复用。G5 使用 `graph_topk_aux_tp4`，与训练通信域分开，所有 rank 调用顺序一致。

## 计时与验收

编译运行 3 步，恢复共同 FULL，重置参考，然后各组统一非测量预热 12 步。开始前完成所有任务，正式 20 步内仅内存记录结果，结束后等待最后辅助链完成。训练回调原有的 loss 获取在各组一致；不使用每步 Host synchronize 建立新增依赖。诊断 profiler 和图转储独立于性能运行。

G0 使用原训练 wrapper，G1～G6 的训练计算沿用同一 wrapper 逻辑。先校验 G0/G1 数值一致、版本计数与非空输出，再做 K10 全扫描 G2～G6 串行与目标并行，扩 K5/K20，然后对瓶颈链测 q=1/8、1/4、1/2、1。1×通过才增加负载。G7/G8 仅对通过或接近预算配置添加，最后用 Qwen3-4B 复核代表点；不宣称跨家族泛化。

必须报告总完成时间、相对 G0/G1 增量、末尾排空、辅助链独立时间、训练段变化、额外峰值 HBM、实际重叠及测量缺口。通过条件是 3% 减速、无积压且无源数据越过写入截止点，同时列 1%/5%。单个通过点只称已测可行点。G7/G8 的设备消费者接受不等于持久化。
